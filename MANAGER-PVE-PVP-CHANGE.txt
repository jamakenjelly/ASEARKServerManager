Manager PVE/PVP classification update

Added an independent "This profile is PVP (unticked = PVE)" tick in:
Server Settings > Administration > Name and Passwords.

The manager classification now controls:
- PVE/PVP main tabs and filters
- PVE/PVP server monitor filters
- PVE/PVP auto-run grouping
- PVE/PVP auto-backup scheduling
- PVE/PVP backup folder selection
- PVE/PVP plugin/profile selection filters

ARK's original ServerPVE/EnablePVP setting remains separate and still controls the actual game mode.

Existing profiles are migrated once: when ManagerEnablePVP is absent, it is initialized from the profile's current ARK EnablePVP value and saved with the profile on the next save.

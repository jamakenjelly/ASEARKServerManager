Version 1.1.0.8
  - ArkApi section: new "Install / Update ArkApi" and "Remove ArkApi" buttons with a status line (installed version, and when a newer one is available). The package (ArkApi 3.56: version.dll, msdia140.dll and a default config.json) comes from this manager's GitHub page. Your plugins in ArkApi\Plugins and the server's config.json are never overwritten, and the server must be stopped first. Remove only takes out version.dll.


Version 1.1.0.7
  - Map Spawner Overrides now only offer the map spawners of the map the profile is set to, plus the base game ones every map shares (and PGM's when PGM is on). Change the map and the list follows. A map that is not in the game data still shows them all, and spawners a profile already uses stay in the list.

  - The Server Options box in Administration is split into labelled boxes: Players and Access, Anti-Cheat and Security, Performance and Stability, Dinosaurs and Spawning, Structures and Meshes, Logging, Network and Connections, and Saves and Clusters. No setting was added or removed; they are only grouped.


Version 1.1.0.6
  - The Plugins button is gone from the header, and the info (?) button now sits next to the Game Data button, as in the ASA manager. It opens an About window: who made the manager, the Discord and GitHub links, and the original project it is based on.


Version 1.1.0.5
  - Fixes a crash at start-up in 1.1.0.4 (the shared styles pointed at icons by the wrong program name). Install this version with the setup file if 1.1.0.4 would not start.


Version 1.1.0.4
  - Two looks, as in the ASA manager: Default (the original beige look) and Light (blue), chosen with the Default / Light buttons in the header. The choice is kept for this PC and shows in every open window at once. Buttons are now light blue and rounded in both looks.


Version 1.1.0.3
  - After the profiles have loaded, the header looks like the ASA manager's: "All n servers loaded" above the All / PVE / PVP buttons on the left, and on the right the public IP, Server Monitor, Update notes, Donate and Check for manager updates (with the version). The header is taller to fit them and has the same banner picture as the ASA manager.


Version 1.1.0.2
  - The manager can now update itself from its own GitHub page: the green "Check for manager updates" button (top right) looks for a newer version, and a newer version shows the green Upgrade bar. It also checks by itself every 30 minutes (Global Settings > Manager Updates).

  - New header buttons: Update notes (this window), Donate and the manager's version.

Version 1.1.0.14
  - The refresh button next to the public IP in the header has the same look as in the ASA manager (small, bordered, same size as the other icon buttons).


Version 1.1.0.13
  - Global Settings has one tick, "Retry on fail until successful", instead of two (as in the ASA manager). Ticked, a failed server or mod download is retried until it works; unticked, it is not retried. Start already saves the profile first (so does a start from the Server Monitor or the main window), and Profile Auto-Save is gone, as in the ASA manager.


Version 1.1.0.12
  - Sync Profile now has a "Player Profile Backup" section of its own (the Enable tick and the number of files to keep), next to Player Access Lists. It used to be copied only as a side effect of syncing Administration.


Version 1.1.0.11
  - Game data from the servers' own files. When the manager starts it reads every mod installed in your servers (ShooterGame\Content\Mods) and writes a game data file for each one, named after the mod (from its .mod file): the mod's items, engrams, creatures, spawn containers and supply crates, so they show in the lists with the mod's name. The base game's files are read the same way for anything the built-in data does not have yet (new items from the master item list, engrams, creatures, spawn containers, supply crates). The files are made again only when a mod or the server build changes, and are used the next time the manager starts. The Game Data window shows the mod's name for these files.

  - + Map / - Map buttons (Administration, next to Total Conversion): add a map to the map list by its launch name and a display name, and remove it again. A map you add is kept in a game data file of its own, so it is still there after a restart.

  - Backups now take the whole save folder of the map (world file, rolling backup files, player, tribe and tribute files and everything else in it), as the ASA manager does, plus SaveGames and the three ini files.


Version 1.1.0.10
  - Exclude Item Indices now has a tick list: every item (621 of them, with its ID number) with a search box and an All / Ticked only / Not ticked only filter. Ticking an item puts its ID on the exclude list, unticking takes it off, and an ID typed in the table ticks the matching item. Each server keeps its own ticks. The item numbers were read from a real ASE server (current game build, including the Aquatica items) with the ItemIdDump plugin. Items from mods have no number here and still have to be typed in.


Version 1.1.0.9
  - The green "A new version of the manager is available" bar with the Upgrade now button now shows under the header when a newer version is found (it was missing, so "Check for manager updates" had nothing to click).


Version 1.1.0.8
  - ArkApi section: new "Install / Update ArkApi" and "Remove ArkApi" buttons with a status line (installed version, and when a newer one is available). The package (ArkApi 3.56: version.dll, msdia140.dll and a default config.json) comes from this manager's GitHub page. Your plugins in ArkApi\Plugins and the server's config.json are never overwritten, and the server must be stopped first. Remove only takes out version.dll.


Version 1.1.0.7
  - Map Spawner Overrides now only offer the map spawners of the map the profile is set to, plus the base game ones every map shares (and PGM's when PGM is on). Change the map and the list follows. A map that is not in the game data still shows them all, and spawners a profile already uses stay in the list.

  - The Server Options box in Administration is split into labelled boxes: Players and Access, Anti-Cheat and Security, Performance and Stability, Dinosaurs and Spawning, Structures and Meshes, Logging, Network and Connections, and Saves and Clusters. No setting was added or removed; they are only grouped.
